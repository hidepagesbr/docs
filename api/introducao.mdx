A **API do HidePages** expõe a plataforma por uma interface REST autenticada com chave de
API. O que você faz no painel, você faz por ela: criar e publicar páginas, conectar domínios,
montar campanhas e funis, rodar testes A/B, gerenciar integrações de conversão e ler os
mesmos números do dashboard.

## Base URL

```text
https://api.hidepages.com/v1
```

Todos os caminhos da referência são relativos a essa base. A API responde apenas por HTTPS.

## Como gerar uma chave

<Steps>
  <Step title="Abra API Keys no app">
    No menu lateral, grupo **Avançado**, clique em **API Keys**.
  </Step>
  <Step title="Crie a chave">
    Clique em **New API Key**, dê um nome que identifique a integração e confirme. Uma conta
    pode manter até **três** chaves ativas.
  </Step>
  <Step title="Copie na hora">
    A chave aparece **uma única vez**. Guarde em um cofre de segredos; o sistema armazena só o
    hash e não consegue mostrá-la de novo.
  </Step>
</Steps>

## Primeira chamada

```bash
curl -s https://api.hidepages.com/v1/pages \
  -H "X-API-Key: hp_live_SUA_CHAVE" \
  -H "Accept: application/json"
```

A resposta é uma lista paginada das páginas do seu workspace ativo:

```json
{
  "data": [
    {
      "id": "cl9cab4c7c25db40658d3222",
      "name": "Black Page | Oferta",
      "slug": "oferta",
      "isPublished": true,
      "createdAt": "2026-09-01T12:00:00Z",
      "updatedAt": "2026-09-20T18:30:00Z"
    }
  ],
  "pagination": { "page": 1, "pageSize": 20, "totalItems": 1, "totalPages": 1, "hasNext": false, "hasPrev": false }
}
```

## Convenções

- Corpos de requisição e resposta são **JSON**. Em escritas, envie `Content-Type: application/json`.
- Campos desconhecidos numa escrita são **recusados com 400**, não ignorados. Um nome de campo
  errado nunca passa em silêncio.
- IDs são strings opacas. Não infira nada do formato.
- Datas e horas são **ISO 8601 em UTC**, exceto onde a referência diz o contrário (as janelas de
  analytics usam o fuso da conta).
- A API é versionada pelo caminho. Mudanças que quebram compatibilidade só chegam em um `/v2`;
  dentro do `/v1` as mudanças são aditivas.

## Ferramentas

A referência é gerada da especificação OpenAPI da API. Você pode baixá-la em
[`/api/openapi.json`](/api/openapi.json) para gerar um cliente na sua linguagem ou importar no
Postman e no Insomnia.
