---

Os endpoints de listagem aceitam `page`, `pageSize`, `sortBy`, `sortDir` e, onde houver
suporte, `search`:

```bash
curl "https://api.hidepages.com/v1/pages?page=1&pageSize=20&sortBy=createdAt&sortDir=desc&search=oferta" \
  -H "X-API-Key: hp_live_SUA_CHAVE"
```

## Formato da resposta

```json
{
  "data": [ /* itens */ ],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "totalItems": 137,
    "totalPages": 7,
    "hasNext": true,
    "hasPrev": false
  }
}
```

- `page` começa em **1**. `pageSize` tem teto de **100**.
- `sortBy` aceita qualquer campo da resposta; um campo inexistente é **400**.
- `search` compara com o nome, sem diferenciar maiúsculas.
- A ordenação segue a collation do banco: maiúsculas vêm antes de minúsculas.

<Note>
Listas são sempre do **workspace ativo** da conta. Para listar outro workspace do qual você é
membro, troque o ativo com `POST /v1/workspaces/{id}/switch`.
</Note>

A única exceção ao envelope é `GET /v1/api-keys`, que responde uma lista simples, porque uma
conta tem no máximo três chaves.
