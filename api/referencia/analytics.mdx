## Analytics

### `GET /v1/analytics/campaign/summary`

**Parâmetros de query:**

| Nome | Tipo | Obrigatório |
|---|---|---|
| `from` | string (date) | sim |
| `to` | string (date) | sim |
| `campaignId` | string | sim |

**Resposta** `200`
