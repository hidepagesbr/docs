<Note>
Base: `https://api.hidepages.com/v1`. Toda requisição precisa do header `X-API-Key`.
</Note>

## API Keys

### `GET /v1/api-keys`

**Resposta** `200`

---

### `POST /v1/api-keys`

**Corpo da requisição** (`CreateApiKeyRequest`):
| Campo | Tipo | Obrigatório |
|---|---|---|
| `name` | string | sim |
| `role` | string | não |

**Resposta** `200`

---

### `DELETE /v1/api-keys/{id}`

**Parâmetros de caminho:**

| Nome | Tipo | Obrigatório |
|---|---|---|
| `id` | string | sim |

**Resposta** `200`

---

### `PATCH /v1/api-keys/{id}`

**Parâmetros de caminho:**

| Nome | Tipo | Obrigatório |
|---|---|---|
| `id` | string | sim |

**Corpo da requisição** (`UpdateApiKeyRequest`):
| Campo | Tipo | Obrigatório |
|---|---|---|
| `isActive` | boolean | não |
| `name` | string | não |

**Resposta** `200`

---
