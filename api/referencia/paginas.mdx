## Pages

### `GET /v1/pages`

**Parâmetros de query:**

| Nome | Tipo | Obrigatório |
|---|---|---|
| `page` | integer (int32) | não |
| `pageSize` | integer (int32) | não |
| `sortBy` | string | não |
| `sortDir` | string | não |
| `search` | string | não |

**Resposta** `200`

---

### `POST /v1/pages`

**Corpo da requisição** (`CreatePageRequest`):
| Campo | Tipo | Obrigatório |
|---|---|---|
| `name` | string | sim |
| `slug` | string | sim |
| `description` | string | não |
| `workspaceId` | string | não |
| `folderId` | string | não |
| `color` | string | não |
| `elements` | JsonNode | não |
| `style` | JsonNode | não |
| `settings` | JsonNode | não |
| `scripts` | JsonNode | não |

**Resposta** `200`

---
