O caminho é o mesmo para todos: **escolher a plataforma → escolher o parâmetro → copiar a URL e colar no gateway**. O que muda de um gateway para outro é a lista de parâmetros e o tipo de integração.

## Tipos de integração

| Tipo | Como o gateway avisa |
|------|---------------------|
| **Webhook / IPN** | O gateway envia os dados da venda para a URL do HidePages. Você cola a URL e pronto. |
| **Postback S2S** | O gateway chama uma URL com os dados da venda na própria URL. O HidePages já monta a URL com as variáveis do gateway (valor, pedido, moeda), então é só colar. |

## Gateways e parâmetros

| Plataforma | Tipo | Parâmetros aceitos | Parâmetro RedTrack |
|------------|------|--------------------|:---:|
| **Hotmart** | Webhook / IPN | `src`, `sck`, `xcod` | ✅ |
| **CartPanda Advertiser** | Webhook / IPN | `src`, `sid2` a `sid5` | ✅ |
| **CartPanda Affiliate** | Postback S2S | `src`, `sid2` a `sid5` | ✅ |
| **BuyGoods Advertiser** | Postback S2S | `subid`, `subid2` a `subid5` | ✅ |
| **BuyGoods Affiliate** | Postback S2S | `subid`, `subid2` a `subid5` | ✅ |
| **Digistore24** | Postback S2S | `sid1` a `sid5` | ✅ |
| **ClickBank** | Webhook / IPN | `vtid`, `unique_aff_sub2` a `unique_aff_sub5` | ✅ |
| **Explodely** | Webhook / IPN | `custom1` a `custom5` | — |
| **Explodely Affiliate** | Webhook / IPN | `affcup`, `tid` | — |
| **Perfect Pay** | Webhook / IPN | `src`, `sck` | — |
| **JVZoo** | Webhook / IPN | `tid` | — |
| **Payt** | Webhook / IPN | `src`, `sck`, `xcod`, `custom1` a `custom5` | ✅ |
| **N8N (Generic Webhook)** | Webhook | qualquer nome, digitado por você | — |

<Info>
A coluna **Parâmetro RedTrack** indica as plataformas que aceitam também um parâmetro `sub1` a `sub20` para o RedTrack no mesmo campo. Veja [RedTrack](/conversoes/redtrack#parâmetro-redtrack-na-integração).
</Info>

## Passo a passo

<Steps>
  <Step title="Conversões → Adicionar integração">
    Selecione até 4 plataformas e clique em **Continuar**.
  </Step>
  <Step title="Escolha o parâmetro">
    Um que o gateway **aceite no link de checkout e devolva na venda**. Um parâmetro só pode ser usado por uma integração.

    <Print src="conversoes/parametros" alt="Tela de parâmetros com um seletor por plataforma" />
  </Step>
  <Step title="Copie a URL gerada">
    Use o botão de copiar da coluna **URL Webhook**.
  </Step>
  <Step title="Cole no gateway">
    Na área de **Webhook**, **IPN** ou **Postback** do gateway, com o evento de venda aprovada.
  </Step>
</Steps>

## Observações por gateway

<AccordionGroup>
  <Accordion title="Hotmart">
    Cole a URL em **Ferramentas → Webhook**, com o evento de compra aprovada. `sck` é o parâmetro mais comum.
  </Accordion>
  <Accordion title="CartPanda">
    **Advertiser** é para quem vende o próprio produto: cole a URL nos webhooks da loja. **Affiliate** é para quem promove: cole a URL de postback na área de afiliado.
  </Accordion>
  <Accordion title="BuyGoods">
    Cole a URL de postback. As variáveis de valor, pedido e tipo de conversão já vêm na URL e são preenchidas pela BuyGoods. Na versão Affiliate, o valor registrado é a comissão.
  </Accordion>
  <Accordion title="Digistore24">
    Cole a URL em **IPN / Postback**. Transações de teste são ignoradas. Para upsell dentro do checkout, veja a fonte [Digistore24 (Upsell)](/campanhas/upsell).
  </Accordion>
  <Accordion title="ClickBank">
    O ClickBank envia os dados criptografados. Informe a **Secret Key** do ClickBank ao criar a integração. Se ela for apagada depois, a integração fica em **Key pendente** até você informar de novo.
  </Accordion>
  <Accordion title="Payt">
    A Payt devolve qualquer parâmetro do link de checkout, por isso aceita a lista mais longa.
  </Accordion>
  <Accordion title="Outro gateway">
    Use o [N8N](/conversoes/n8n) como ponte: ele recebe a venda do seu gateway e reenvia ao HidePages.
  </Accordion>
</AccordionGroup>

## Boas práticas

<Check>
  - O parâmetro escolhido no HidePages é o **mesmo** que o gateway grava no pedido.
  - Não use esse parâmetro para outra coisa na URL do anúncio: o HidePages sobrescreve o valor nos links de checkout.
  - Vendas de teste podem ser descartadas. Uma venda real, mesmo de valor baixo, é o teste mais confiável.
</Check>

## Como saber que funcionou

Depois da primeira venda, o status passa de **Aguardando 1ª venda** para **Integrado**, e a conversão aparece no [Dashboard](/painel/dashboard) e nas métricas da campanha.
