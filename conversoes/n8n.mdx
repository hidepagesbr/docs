Quando o seu gateway **não está na lista**, use o **N8N** como ponte: ele recebe a venda do gateway e reenvia ao HidePages no formato abaixo.

## Configurar

<Steps>
  <Step title="Adicione a integração N8N (Generic Webhook)">
    Em **Conversões → Adicionar integração**. No passo de parâmetros, **digite** o nome do parâmetro que o seu gateway aceita no link de checkout e devolve na venda (ex.: `subid4`).
  </Step>
  <Step title="Abra as instruções">
    Na tabela de integrações, clique no **?** ao lado de **N8N (Generic Webhook)**.

    <Print src="conversoes/n8n-instrucoes" alt="Diálogo Webhook N8N com o template para baixar, o body JSON de exemplo e a lista de campos" />
  </Step>
  <Step title="Baixe o template">
    **Baixar template N8N** gera um workflow com a URL e o parâmetro já preenchidos. No N8N, importe em **⋮ → Import from file**.
  </Step>
  <Step title="Ligue o gateway ao N8N">
    O workflow recebe o webhook do gateway e, num nó **HTTP Request**, faz um `POST` para a URL da integração.
  </Step>
</Steps>

## A requisição

- **Método:** `POST`, com `Content-Type: application/json`.
- **Autenticação:** o `?token=...` já está na URL. Não envie no JSON.

```json
{
  "conversion_key": "hp1_...",
  "order_amount_cents": 4990,
  "currency": "USD",
  "product_name": "Product Name",
  "category": "initial_sale",
  "order_id": "ORD-123"
}
```

## Campos

| Campo | Obrigatório | Descrição |
|-------|:---:|-----------|
| `conversion_key` | ✅ | O valor `hp1_...` que o gateway devolveu no seu parâmetro. Envie sempre com o nome `conversion_key`, não com o nome do parâmetro. |
| `order_amount_cents` | — | Valor em **centavos**: `4990` = US$ 49,90. Também aceita `amount_cents`. |
| `category` | — | `initial_sale` ou `sale`. Outros valores (reembolso, upsell…) são ignorados. Se omitido, conta como venda. |
| `order_id` | — | ID do pedido, ou `transaction_id`. Recomendado, para não contar a mesma venda duas vezes. |
| `currency` | — | Padrão `USD`. |
| `product_name`, `product_id` | — | Dados do produto. |
| `email` ou `customer_email` | — | E-mail do comprador. |

<Warning>
Cuidado com o valor. `order_amount_cents: 4990` é US$ 49,90. Um campo `amount`, sem `_cents`, é lido em **dólares**: `amount: 4990` vira US$ 4.990,00.
</Warning>

## Testar

Execute o workflow no N8N com uma chave `hp1_...` real, copiada de um link de checkout da sua Black Page. Se o POST responder com sucesso, a integração passa para **Integrado**.
